strategy: prefer

Two children produce the same binary path. The rule names one authoritative source, so the overlap is explicit.

Before composition:
route each child file.

Dependency controls decide whether a child file participates, emits automatically, or becomes visible to parent Jinja.

exclude

Remove completely

The file does not auto-emit. It also cannot be used by render, concat, or prefer.

exclude:
  - docs/internal/**
suppress

Do not auto-emit

The file remains available to an explicit compose rule. This control resolves intentional overlaps.

suppress:
  - README.md
context

Expose text to Jinja

The parent can read allowlisted UTF-8 text. This control does not decide final ownership.

context:
  - README.md
pass-through

Emit uncontested output

One active child produces the path. The parent does not overlap it, so no compose rule is necessary.

    context: [README.md, Makefile]

  - name: docker
    repo: https://github.com/getscaf/copier-docker.git
    ref: "v2.0.1"
    answers:
      project_name: "{{ project_name }}"
      base_image: "python:{{ python_version }}-slim"
    suppress: [README.md, Makefile]
    context: [README.md, Makefile]

  - name: ci
    repo: https://github.com/getscaf/copier-github-actions.git
    ref: "v0.3.2"
    answers:
      project_name: "{{ project_name }}"
      language: "python"
    suppress: [README.md]
    context: [README.md]

compose:
  "README.md":
    strategy: render
  "Makefile":
    strategy: render
  ".gitignore":
    strategy: concat
    sources: [python, docker, ci]
    separator: "\n\n"
    dedupe_lines: true
    header: "# Generated by Scaf Compose\n"
